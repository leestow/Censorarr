CENSORARR v1.6.9 — FIRST INSTALL

1. Copy or clone the Censorarr source to your Docker host.
2. Edit docker-compose.yml and set your host-side Movies/TV paths, PUID, PGID, timezone, and optional integration credentials.
3. Start the project:
     docker compose up -d --build
4. Open the web UI on the configured host port.
5. Complete the Setup Wizard.
6. Begin with a small test folder or a small number of files before expanding to the full library.

Persistent runtime data belongs under /config and /work.
The default log is /config/censorarr.log.
The default completion marker is .censorarr.done.json.

Self-test:
  docker exec -it censorarr python /app/selftest.py


Synology permission compatibility (introduced in v1.6.5; current in v1.6.9):
- CENSORARR_SYNOLOGY_COMPAT_MODE=auto is recommended for DSM Container Manager.
- auto uses PUID/PGID normally and falls back to container root only if DSM ACLs block that identity from a media mount while root can access it.
- false forbids root fallback; true always uses container root.
- Censorarr checks media access before loading Whisper and waits with a clear permission error instead of crash-looping.
- Nested media ACL checks and automatic retry of permission failures remain supported in v1.6.9.
